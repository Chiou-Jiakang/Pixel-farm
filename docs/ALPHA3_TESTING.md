## 本機瀏覽器人工驗收（待執行）

- [ ] 頁首、頁尾版本皆為 alpha.3；從 `npm start` 啟動。
- [ ] 首次進入遊戲不會自動播放音效；點擊後才能播放。
- [ ] 播種／收成／購買／販售成功音效正確，數量與金幣仍由後端確認。
- [ ] 金幣或種子不足時，顯示文字錯誤，不播放成功音效。
- [ ] 成熟提示只播放一次，不會每 500ms 重複。
- [ ] 靜音開關與音量滑桿正常，重新整理後偏好保留。
- [ ] 使用不同分頁時不會產生持續、重複的成熟提示音。
- [ ] 手機 Edge／Chrome 或指定瀏覽器與鍵盤操作。
- [ ] 已勾選系統減少動畫時仍可正常操作。
- [ ] SQLite 存檔重新整理與重啟後保持一致；`data/pixel-farm.sqlite` 未遭覆蓋。
