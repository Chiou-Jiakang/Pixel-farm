# Pixel Farm v0.5.0-alpha.1 — Pixel UI Refresh

> 狀態：開發交付／尚待使用者本機驗收；不是 GitHub Release。

## 已製作
- 像素化農田色調與土壤方格、面板邊框與操作回饋。
- 自製 SVG 像素作物素材（胡蘿蔔、馬鈴薯、番茄及生長階段）。
- 成熟作物輕微動畫、減少動畫偏好支援、鍵盤焦點樣式。
- 保留 v0.4.0 的 Express、SQLite、交易規則及 REST API。

## 測試與限制
- 原本 17 項 Node 自動化測試應於本機重新執行；不可將先前 v0.4.0 結果視作新版通過。
- 本 alpha 版尚待瀏覽器驗收、跨裝置排版與持久化回歸驗證。
- v0.5.0 的音效與進階動畫尚未實作。
