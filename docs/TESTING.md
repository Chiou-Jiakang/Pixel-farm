### v0.2.0 截圖一致性核對

- 播種次數：66；收成數量：57；成長中：0。
- 分類收成：胡蘿蔔 35、馬鈴薯 6、番茄 16；`35 + 6 + 16 = 57`，與收成總數相符。
- 差值 `66 - 57 = 9`；截圖中可見 9 格成熟作物，與當時畫面數量相符。

這僅是**單次畫面的邏輯一致性檢查**，不能據此斷言全部極端情況都沒有問題。

## 3. 尚未驗證／不屬本版範圍

- 後端 API、SQLite、交易一致性、伺服器時間驗證、存檔恢復：尚未實作，不適用。
- 不同時區、瀏覽器時間被修改後的行為：未正式驗證。
- 多裝置／跨瀏覽器相容性、鍵盤與輔助科技完整可及性：尚無完整測試紀錄。
- 自動化回歸測試、負載測試：尚無測試報告。

## 4. v0.3.0 預計新增測試（未執行）

- 金幣不足時禁止購買。
- 種子庫存不足時禁止播種。
- 成熟收成只增加一次作物庫存。
- 背包不足時禁止販售。
- 購買／販售後金幣、庫存與交易紀錄一致。
- 重設後經濟狀態符合規格。

## 5. v0.4.0 預計新增測試（未執行）

- 重新整理或重啟伺服器後仍可載入遊戲狀態。
- 重複或並發的收成／交易請求不造成重複獎勵。
- 非法 API 請求、無效作物 ID、負數數量被拒絕。
- 改動瀏覽器時間不應直接決定後端成熟結果。
