# PRD｜Pixel Farm 產品需求文件

## 產品定位
使用瀏覽器體驗種植、等待、收成、販售的單人輕量農場遊戲，藉此演練前端互動、狀態管理、經濟規則與後續全端資料交易。目標是 v1.0.0 可在本機執行、具有 SQLite 存檔的全端 MVP。

## 版本邊界
- **v0.1.0 已發布**：4×4 農田、播種、成熟收成。
- **v0.2.0 已發布**：三作物與階段成長。
- **v0.3.0 已開發，待瀏覽器驗收及發布**：種子購買、金幣、背包、販售、淨現金流、交易紀錄；所有狀態僅在前端記憶體。
- **v0.4.0 規劃**：Node.js、Express、SQLite、REST API、資料一致性與持久化。
- **v0.5.0 規劃**：視覺效果、音效、響應式優化。
- **v1.0.0 規劃**：完整測試、錯誤處理、穩定發行。

## v0.3.0 功能需求與驗收

| ID | 需求 | 驗收條件 |
|---|---|---|
| FARM-01 | 16 格農田 | 空地可播種；佔用格不得重播 |
| CROP-01 | 三作物成長 | 胡蘿蔔 10 秒、馬鈴薯 18 秒、番茄 30 秒；成熟才能收成 |
| ECON-01 | 金幣系統 | 初始 120；購買扣款，販售加款，金幣不可因合法操作變負數 |
| SHOP-01 | 商店 | 每次可買 1／5 顆種子；不足金幣不得交易 |
| BAG-01 | 背包 | 播種扣種子；收成增作物；販售扣作物 |
| ECON-02 | 結算資訊 | 累計支出、累計收入、淨現金流 = 收入－支出 |
| ECON-03 | 交易紀錄 | 記錄最近 20 筆買賣，顯示金額變動 |
| RESET-01 | 農場重設 | 恢復初始資金、3 顆胡蘿蔔種子、空農田、零統計 |
| UX-01 | 操作提示 | 失敗交易告知原因，禁止未成熟收成 |

## v0.3.0 遊戲數據

| 作物 | 成熟 | 種子價格 | 售價 |
|---|---:|---:|---:|
| 胡蘿蔔 | 10 秒 | 8 | 14 |
| 馬鈴薯 | 18 秒 | 14 | 25 |
| 番茄 | 30 秒 | 22 | 40 |

此為遊戲平衡初始假設，可在未來版迭代調整。初始背包有 3 顆胡蘿蔔種子。

## 非功能需求
- 可從 `file://` 直接開啟 `public/index.html`，不依賴 CDN 或後端。
- 鍵盤可選擇種子及農田格子；操作提示有 `role="status"`。
- 維持可辨識的桌面 UI 與基本窄螢幕版面。
- 經濟規則與 DOM 渲染分離，使未來可轉移至後端。

## 明確不在 v0.3.0 範圍
登入、多玩家、資料同步、SQLite、資料庫交易、持久化、反作弊、安全身份驗證、自由走動、天氣、季節、農田升級。這些不能宣稱已完成。
