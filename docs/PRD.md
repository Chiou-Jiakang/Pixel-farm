# PRD｜Pixel Farm 產品需求文件

## 產品定位
單人本機農場經營網頁遊戲，練習前端狀態、後端 REST API、SQLite 持久化與交易一致性，目標 v1.0.0 完成可維護的本機全端 MVP。

## 已完成版本
- v0.1.0：4×4 農田播種與收成。
- v0.2.0：三作物、四階段成長。
- v0.3.0：金幣、商店、背包、販售及交易紀錄；已發布 Pre-release。

## v0.3.0 歷史需求基準（原版本規格，保留以利追溯）

| ID | 需求 | 驗收條件 |
|---|---|---|
| FARM-01 | 16 格農田 | 空地可播種；佔用格不得重播 |
| CROP-01 | 三作物成長 | 胡蘿蔔 10 秒、馬鈴薯 18 秒、番茄 30 秒；成熟才能收成 |
| ECON-01 | 金幣系統 | 初始 120；購買扣款，販售加款，金幣不可因合法操作變負數 |
| SHOP-01 | 商店 | 每次可買 1／5 顆種子；不足金幣不得交易 |
| BAG-01 | 背包 | 播種扣種子；收成增作物；販售扣作物 |
| ECON-02 | 結算資訊 | 累計支出、累計收入、淨現金流 = 收入－支出 |
| ECON-03 | 交易紀錄 | 顯示最近 20 筆買賣與金額變動（v0.3.0 僅本局記憶體） |
| RESET-01 | 農場重設 | 恢復初始資金、3 顆胡蘿蔔種子、空農田、零統計 |
| UX-01 | 操作提示 | 失敗交易告知原因，禁止未成熟收成 |

**歷史架構備註：** v0.3.0 可由 `file://` 直接執行、沒有 SQLite、沒有後端身份驗證；v0.4.0 已改為伺服器啟動模式。這些原需求不代表 v0.4.0 仍適用前端直開方式。

## v0.4.0 開發範圍（17 項自動化測試與 5 項持久化人工驗收已通過；待發布）
| ID | 需求 | 驗收方式 |
|---|---|---|
| API-01 | `GET /api/game` 回傳當前資料 | API 測試，重複查詢一致 |
| API-02 | Buy/Plant/Harvest/Sell/Reset HTTP 操作 | 合法操作成功、非法操作 400 |
| DB-01 | SQLite 保存金幣、農地及背包 | 重新整理後資料不變 |
| DB-02 | 重啟伺服器後仍保留資料 | 關閉伺服器重新啟動並查驗 |
| TX-01 | 買賣與種植具原子性 | 失敗操作不得寫入部分狀態 |
| TIME-01 | 後端按時間戳判斷成熟 | 停止瀏覽器後仍能成熟 |
| TX-02 | 防止重複收成、餘額不足與庫存負數 | API 與手動負面測試 |
| UX-01 | 前端沿用 v0.3.0 的基本 UI | Chrome/Edge 開啟伺服器網址驗收 |

初始金幣 120、初始胡蘿蔔種子 3 顆、16 格空農田。最近 20 筆交易呈現於 UI，完整交易資料保留於本機資料庫。

## 非功能需求
- 本地單人使用；伺服器僅監聽 127.0.0.1，不支援公網部署。
- 資料庫檔案加入 `.gitignore`，不應納入版本管理。
- API 以 JSON 回傳，讀取與交易不依賴前端 `setTimeout` 的結果。
- 不支持未授權網際網路使用，不保證多使用者身份隔離。

## v0.4.0 驗收結果
- 使用者於 Node.js v24.15.0 本機完成 17 項自動化測試（含 2 項 API）。
- 使用者回報 5 項 SQLite 持久化人工驗收通過；尚未進行全套跨瀏覽器、負載及安全性評測。

## 不在本版範圍
會員登入、多人帳戶、雲端同步、任務系統、音效、天氣、進階反作弊與效能承諾。
