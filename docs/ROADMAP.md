## v0.3.0 已完成事項
- 使用者回報在自己的瀏覽器完成購買、播種、成長、收成、販售及重設等核心功能驗收。
- 程式與文件 Commit → Push → Tag `v0.3.0` → GitHub Pre-release 已完成。
- 後續改善項目：種子不足的提示可更清楚；舊版解壓縮副本應繼續排除在 Git 追蹤之外。

## v0.4.0 重點
- 以伺服器為遊戲資料唯一可信來源；交易必須使用原子資料庫操作。
- 伺服器端以時間戳計算成熟，不依賴 `setTimeout()` 作存檔機制。
- SQLite 表規劃包含存檔、農地、背包、價格設定和交易紀錄。
- 防止重複收成、並發交易、扣款負值；加上 API 整合測試。
