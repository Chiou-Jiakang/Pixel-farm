## 下一階段：v0.3.0（尚未實作）

- 為作物定義測試用種子價格、販售價格與初始金幣。
- 在前端建立種子及收成作物背包。
- 購買種子時檢查金幣並更新庫存；播種時扣除種子。
- 成熟收成時增加背包作物數；販售時扣除庫存、增加金幣。
- 顯示交易結果與成本、收入、利潤的定義。
- 測試不足金幣、庫存不足、同一作物重複操作等例外。

**版本邊界**：v0.3.0 可先用前端記憶體狀態驗證流程；持久化、伺服器權威交易在 v0.4.0 完成。

## v0.4.0 重要工程風險

1. 成熟時間不應由前端任意宣告，須後端依播種時間判斷。
2. 購買、收成、販售需資料庫原子交易，避免負數資產或重複獎勵。
3. API 必須驗證格子、作物、數量和目前狀態。
4. SQLite 資料須能在重新整理頁面或重啟伺服器後恢復。
5. 需處理重複請求、錯誤回應與狀態重新載入。

## 發布標準

- 功能有可操作版本，重要異常狀況已驗收。
- 更新 `README.md`、`CHANGELOG.md`、`docs/DEVLOG.md`、`docs/TESTING.md`。
- `PRD.md` 與本 ROADMAP 若需求變更則同步修正。
- 完成 Commit、Push、Tag，最後發布對應 Release；未完成的工作不能標為已發布。

## 不在 v1.0.0 範圍

多人即時連線、帳號管理、雲端部署、動物、季節、天氣、地圖擴建及自由移動角色暫列候選擴充，不作為 v1.0.0 驗收必要條件。
