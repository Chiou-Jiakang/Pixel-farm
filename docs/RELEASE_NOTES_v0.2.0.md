# Pixel Farm v0.2.0 — Crop Growth System

Pixel Farm v0.2.0 是第二個前端原型版本，延續 v0.1.0 的 4 × 4 農田，加入三種作物、分階段成長及收成分類統計，讓種植與等待更有變化。

## 新增功能

- **三種可種植作物**：胡蘿蔔、馬鈴薯、番茄。
- **不同成熟時間**：胡蘿蔔 10 秒、馬鈴薯 18 秒、番茄 30 秒。
- **四個成長階段**：種子、幼苗、成長中、成熟。
- **作物選擇區**：選定品種後點擊空地播種。
- **分類收成統計**：獨立記錄三種作物的收成數量。
- **操作提示與限制**：已種植農地無法重複播種，未成熟作物不能提前收成。

## 延續功能

- 4 × 4 農田、播種與收成總數、成長中數量、農田重設。
- HTML5、CSS3、JavaScript 的基本響應式介面。

## 測試與驗收

開發者回報三種作物播種、各別成熟時間、成長階段、提前收成防護、成熟收成更新統計，以及農田重設等 **6 項手動驗收全部通過**。實際遊戲畫面中的分類收成數量加總與總收成一致。本次沒有附帶獨立可稽核的自動化測試報告。

## 執行方式

下載 Source code ZIP，解壓縮後以 Microsoft Edge 或 Chrome 開啟 `public/index.html`，即可執行。v0.2.0 **不需要** Node.js、npm 或資料庫。

## 已知限制

- 目前為**純前端原型**，重新整理或關閉網頁會失去進度。
- 作物成熟以瀏覽器本機時間計算，尚未加入後端驗證。
- 尚無商店、金幣、背包與 SQLite。
- 作物成熟秒數為原型測試設定，未必是最終遊戲平衡值。

## 下一版本：v0.3.0

預計加入商店、種子與作物背包、金幣、購買與販售，以及基本經濟平衡。
