# Pixel Farm v0.5.0-alpha.3｜開發日誌

## 開發範圍

- 以先前 alpha.2 交付快照為實作起點；GitHub `3e62460` 為使用者確認的目標主分支基準，但本環境無法直接擷取該 Commit 原始碼，**尚未完成逐檔 Git 樹比對**。
- 加入 `public/sound-core.js`（純函式音效規則）、`public/audio.js`（Web Audio API 音效合成）。
- 播種、收成、購買、販售及重設：收到後端成功回覆後才播放成功音效。
- HTTP/API 操作失敗或網路異常：使用錯誤提示音；不改變交易資料。
- 成熟提醒只在從非成熟轉換成成熟狀態時播放；首次載入不播放。
- 靜音與音量控制，偏好儲存在 `localStorage`；音效首次須使用者互動以符合瀏覽器自動播放限制。
- 不修改後端遊戲規則或 SQLite schema；未建立或打包任何遊戲存檔。

## 實作限制

- 音效由 Web Audio API 即時合成，不提供 MP3／音訊素材。
- 不保證各瀏覽器的合成器音色完全相同。
- 純函式測試與本地後端整合測試的實際結果，見 `ALPHA3_TEST_REPORT.md`；瀏覽器聲音仍須使用者本機驗收。
