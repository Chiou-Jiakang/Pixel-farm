# Pixel Farm｜像素農場經營遊戲

> **目前開發版本：v0.2.0 — 作物成長系統**  
> 專案狀態：前端原型已通過使用者手動驗收；**v0.2.0 尚待 Git Commit、Push、Tag 與 GitHub Release**。  
> GitHub：https://github.com/Chiou-Jiakang/Pixel-farm

## 專案簡介

Pixel Farm 是一款俯視視角、以格子操作的像素風格農場經營網頁遊戲。玩家在 4 × 4 農田上選擇作物、播種、等待成熟，再進行收成。專案採迭代式開發：先驗證前端遊戲循環，再逐步加入商店、背包、經濟系統及後端持久化。

目前 **不是已完成的全端產品**。Node.js、Express 與 SQLite 是後續版本預計導入的技術，尚未整合至 v0.2.0。

## 目前功能（v0.2.0）

- 4 × 4 農田，共 16 格，可點擊播種與收成。
- 選擇三種作物：胡蘿蔔（10 秒）、馬鈴薯（18 秒）、番茄（30 秒）。
- 四個成長階段：種子、幼苗、成長中、成熟；另有空地狀態。
- 根據播種時間戳記與目前瀏覽器時間計算成長進度；頁面仍開啟時切換分頁，回到頁面可依經過時間更新。
- 防止已播種格子重複播種、未成熟提前收成；成熟後收成並恢復空地。
- 顯示播種次數、收成總數、尚在成長的作物數及各作物收成數量。
- 提供農田重設功能、狀態提示、基本響應式版面。

## 技術架構與執行需求

- **已使用**：HTML5、CSS3、原生 JavaScript（無框架）。
- **目前運行方式**：直接使用現代瀏覽器開啟本機 HTML；v0.2.0 不需要 npm、伺服器或資料庫。
- **規劃中**：Node.js、Express、REST API、SQLite。

## 本機執行

1. 下載或複製專案，確認 `public/index.html`、`public/style.css`、`public/script.js` 均存在。
2. 在 Windows 檔案總管中雙擊 `public/index.html`，使用 Edge 或 Chrome 開啟。
3. 選擇作物、點擊空格播種，成熟後點擊收成。

也可在 VS Code 以 Live Server 開啟 `public/index.html`（選用）。目前 **不需要** `npm install` 或 `npm start`。

## 操作說明

1. 在作物選擇區選擇胡蘿蔔、馬鈴薯或番茄。
2. 點擊「可播種」的空地種植選定作物。
3. 作物進入種子、幼苗、成長中，最後成熟；未成熟時無法收成。
4. 成熟作物顯示「收成！」，點擊後計入收成紀錄，該格恢復空地。
5. 如需重新開始，可使用「重設農場」；此操作會清空目前頁面的農田與統計。

## 測試狀態

2026-10-19，專案開發者於對話中回報 v0.2.0 六項功能手動驗收全部通過，並提供實際遊戲畫面。該畫面可觀察到三種作物介面、4 × 4 農田、收成分類統計與 v0.2.0 版本標示。**沒有獨立保存的自動化測試報告**；詳細驗收範圍與證據等級見 [`docs/TESTING.md`](docs/TESTING.md)。

## 已知限制

- 重新整理或關閉網頁會重新初始化進度，沒有持久化存檔。
- 成長依瀏覽器本機時間判斷，無伺服器時間驗證，可受系統時間調整影響。
- 尚未加入種子成本、金幣、背包、商店、交易紀錄及資料庫。
- 成熟秒數目前為方便測試的原型數值，日後可能調整。
- 目前是單人本機瀏覽器原型；未實作帳號、多玩家或正式部署。
